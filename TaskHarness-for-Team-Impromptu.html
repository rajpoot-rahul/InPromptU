Task Harness: Impromptu's quality gate

Impromptu improves the question. Task Harness checks the answer.

In one minute

AI is usually right but sometimes quietly wrong. Task Harness (built by Surekha) wraps any AI call in a quality gate: a fixed template defines the task, plain code checks every answer against the source (values present, taken from the right place, sums add up, correct format), the AI gets one retry with the exact problem, and anything still failing goes to a person instead of passing silently.

Proof: on 30 invoices with Claude on Hyland's AWS account, the cheapest model with the harness got 30/30 correct with 0 silent errors, about 2.6× faster and ~38× cheaper than the most expensive model with a plain prompt (which silently got 6/30 wrong on the cheap model, and gave 15/30 wrongly formatted answers on the expensive one).

How it fits Impromptu

Impromptu's "Improve prompt" step (src/provider.cjs → requestImprovement) asks the model to preserve every fact and constraint, but only checks the shape of the reply. The harness adds the missing checks: nothing lost (names, numbers, dates, links, every "not"), nothing invented, skill followed; one retry; a clear warning to the user.

Honest status: Task Harness works today as a separate prototype (web app, CLI, 69 automated tests, real results). The integration into Impromptu is the planned next step, not built yet. The video segment says so.
