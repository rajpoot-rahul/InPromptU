What it is, in one minute

AI is usually right but sometimes quietly wrong. Task Harness is a reusable quality gate around any AI call:

Pick task (template) → Clean → Build prompt → AI answers → Code checks → One retry or human review → Log

The checks are plain code: is every value really in the source, is it from the right line (not the due date, not the customer, not a PO number), do the sums add up, is the format exactly right. Nothing wrong passes silently.

One line: "Impromptu improves the question. Task Harness checks the answer."
Analogy: the AI is a fast new employee; the harness is the checklist and the supervisor.

Two tasks are built: Invoice extraction (30 test invoices with known answers, so accuracy is measured) and Key facts from any text (summary, key points with exact quotes, names, dates, numbers, action items; 8 example texts included).

Start the demo app

  1. If it has been a few hours, sign in to AWS (needed for Live mode only): 
    aws sso login --sso-session <your-sso-session>
  2. Start the app (from the task-harness folder): 
    .venv/bin/python -m taskharness serve --aws-profile <your-aws-sso-profile>
  3. Open http://127.0.0.1:8000. Keep the Terminal open; press Ctrl + C to stop.
"Address already in use" means an older copy is still running: stop it with Ctrl + C in its Terminal window first. Saved run works offline; Live needs internet and a current AWS sign-in.

Likely questions

  • "Doesn't Brainware already do invoices?" Yes, for classic capture, and we are not replacing it. Invoices are our test case because the answers are easy to verify. The gap is generative-AI calls, which usually have no standard checks.
  • "Isn't this just better prompting?" No. The prompt is one step; the value is that code checks every answer and nothing wrong passes silently.
  • "Doesn't Claude check itself?" No. It can be confidently wrong; our test showed 6 of 30 silent errors from the cheap model alone.
  • "Is it tied to one model?" No. It works with Claude on Bedrock, the Anthropic API or OpenAI; only the model name changes.
  • "Is the data real?" Synthetic invoices and example texts with no customer data. Next step: real, approved documents from one team.
  • "Is it in Impromptu already?" Not yet. It works as a separate prototype; plugging it into Impromptu's prompt rewrite (src/provider.cjs) is the next step.

Honest limits

  • 30 synthetic invoices and two tasks so far; checks are written per task.
  • For "Key facts", checks prove quotes, names, dates and numbers are in the text, not that the meaning of a summary is right.
  • Invoice capture itself already exists (Brainware); costs are list-price estimates.
  • Not yet integrated into Impromptu or the AI gateway.
