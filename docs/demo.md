# Impromptu demo walkthrough

## Before the demo

Install or extract the appropriate [v0.2.1 build](https://github.com/rajpoot-rahul/InPromptU/releases/tag/v0.2.1). Open Impromptu and choose an appearance in Settings.

For the live knowledge demonstration, use your own compatible local Codex installation, sign-in, and enabled Atlassian connector. Choose a Confluence page or Jira issue you are allowed to show to the audience. Test that particular lookup beforehand. The app contains no preloaded company documents or account credentials.

## A three-minute walkthrough

1. **The situation:** explain that an employee has received a short comment whose background is unclear. Copy an appropriate sample message containing a known issue key or topic.
2. **The shortcut:** press Command+Shift+I on Mac or Ctrl+Shift+I on Windows. Show the text appearing in Knowledge & reply. This workflow requires copying first.
3. **The context:** connect via Codex, refine Search focus if needed, and select Find context & draft reply. Show the retrieved sources and supporting passages.
4. **The judgment:** identify a documented fact and an unresolved question. Open a source if useful. Edit the reply and copy it with citations. Sending it remains the employee's decision.
5. **The coaching:** switch to Prompt workspace and try a synthetic brief such as “Summarise these notes for a project update.” Add sample context, audience, and output format; choose a starter skill and review the improvement.
6. **The close:** explain the proposed evaluation: better accepted answers, fewer retries, and measured total cost per task. Show the concept document for planned features.

## If a connection is unavailable

Use offline prompt coaching and explain that it structures the prompt with a template. If source retrieval works but AI drafting does not, show the sources-only result. Do not present a fallback template as a generated, evidence-backed reply or invent a successful live lookup.

## State the current limits

The Mac application has been exercised locally. Windows is packaged but still needs testing on Windows. Builds are unsigned. The knowledge bridge uses experimental Codex APIs and depends on each employee's permissions. Billing reconciliation, automatic routing, organisation dashboards, and employee leaderboards are future concepts.
