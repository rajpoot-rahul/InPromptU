# Impromptu v0.2.1 — hackathon preview

A desktop companion for prompt coaching, Hyland knowledge lookup, and source-backed reply drafting. This preview includes System, Light, and Dark appearance modes.

## Downloads

Open the Assets section of this release:

- **Impromptu-0.2.1-Mac-Apple-Silicon-Installer.pkg** — macOS installer; places Impromptu in Applications. Requires an Apple Silicon Mac with macOS 13 or later.
- **Impromptu-0.2.1-Mac-Apple-Silicon.zip** — portable Mac application.
- **Impromptu-0.2.1-Windows-x64.zip** — portable Windows x64 application. Extract the entire ZIP and open Impromptu.exe; keep its supporting files together. This is not a Windows Setup.exe installer.
- **SHA256SUMS.txt** — checksums for the three application downloads.

GitHub's automatic Source code ZIP/tar.gz downloads contain project source, not the packaged applications. Save drafts and quit an older Impromptu before opening an updated copy.

## Getting started

Open Impromptu from Applications on Mac, or from the extracted Windows folder. Copy text, then press **Command+Shift+I** on Mac or **Ctrl+Shift+I** on Windows while Impromptu is running. Choose **Settings → Appearance → Dark** for dark mode.

Offline prompt coaching works without an account or model service. Hyland knowledge lookup requires a compatible local Codex executable, your own sign-in, and the enabled Atlassian connector for hyland.atlassian.net. Reply generation uses the Codex account's model access. Prompt rewriting can optionally use local Ollama or an approved Chat Completions API.

## Validation and limitations

- All 18 automated checks pass.
- Mac launch and native desktop features were exercised locally; appearance switching was also verified in an isolated Electron window.
- The Mac installer payload was expanded and compared with the packaged app, including hashes, links, and executable permissions. The macOS Installer wizard has not been tested end to end.
- Windows was cross-packaged on Mac and **has not been run on Windows**. Windows shortcut and Codex-connector compatibility still need testing.
- Builds and installer are unsigned; the Mac build is not notarized. Managed-device installation policies may require IT approval.
- The knowledge bridge uses experimental app-server APIs tested with Codex CLI 0.165.0-alpha.1.2. Compatibility can vary with versions and organisation policies.
- The employee reviews the evidence and reply; nothing is automatically sent to Teams or written to Jira/Confluence.
- Cost savings, automatic model routing, provider billing auditing, and employee rankings are not implemented or claimed.

The repository contains the source, build scripts, concept, demo guide, and screenshots. Application assets are stored with this release rather than in Git history.
