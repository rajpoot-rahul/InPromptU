# Impromptu v0.2.8 — Mac and Windows

Mac Apple Silicon and Windows x64 installers built and tested from the same commit. This release adds local AI, Windows parity, Hyland latest learning and prompt insights.

## Downloads

- **[Mac installer (.pkg)](https://github.com/rajpoot-rahul/InPromptU/releases/latest/download/Impromptu-Mac-Apple-Silicon-Installer.pkg)** — Apple Silicon, macOS 13 or later.
- **[Windows installer (Setup.exe)](https://github.com/rajpoot-rahul/InPromptU/releases/latest/download/Impromptu-Windows-x64-Setup.exe)** — Windows x64.
- `release.json` and `SHA256SUMS.txt` record the version, commit and checksums of both installers.

Save drafts and quit the old app before upgrading. Settings and saved sessions are retained.

## What's new

- **Local AI setup and local chat** ([#1](https://github.com/rajpoot-rahul/InPromptU/pull/1)). One-click, consented setup of a local AI runtime (installed only after its code signature checks out), a recommended local model for the machine, and a test before saving. Local-only mode is enforced in the main process. Also adds streaming local chat with erasable history, the Improve / Compress / Explain prompt workspace with Hyland evidence, Skillify, the Learner track, context packs for Cursor, Claude Code and Codex, multi-turn Bedrock, and an opt-in on-screen mascot.
- **Windows parity** ([#2](https://github.com/rajpoot-rahul/InPromptU/pull/2)). The local AI installer signature is pinned to the vendor's exact certificate; PowerShell calls are hardened; per-user silent install of the local AI runtime with disk-space checks; a fixed mascot copy shortcut; full clipboard restore (text, HTML, RTF, image) on both platforms; a full-colour tray icon; Windows-specific wording; and Codex discovery through the npm shim.
- **Hyland latest learning** ([#3](https://github.com/rajpoot-rahul/InPromptU/pull/3)). Track Hyland AI discussion sessions imported from a folder or pasted from a Teams recap: summaries, action items, attachments, Attended/Reviewed status and private notes, with optional AI summaries and a "Catch me up" digest. Links and local files open only through strict allowlists. The learning folder is now checked by a light 10-second poll instead of a file watcher, so new and edited sessions are noticed the same way on Windows and macOS, and Windows paths (backslashes, drive letters, UNC paths, CRLF files) are handled.
- **Prompt insights in My progress** ([#4](https://github.com/rajpoot-rahul/InPromptU/pull/4)). A local prompt history (on by default, erasable and exportable) drives a Prompt Specificity score, signal coverage trends, ranked areas to improve with your own examples, habits, and reading from official prompting guides. An AI coaching summary runs only when you ask for it.
- **Release and CI.** Windows CI no longer hangs after the desktop tests: the test harness now runs the app's quit cleanup, closing folder watchers.

## Known limitations

- Builds and installers are unsigned, and the Mac build is not notarized. macOS Gatekeeper and Windows SmartScreen may warn before opening them; managed devices may need IT approval.
- On macOS, the mascot's Accessibility and Screen Recording permissions may need to be granted again after updating, because the release build's signature differs from the previous one.
- Still needs testing on a real Windows PC: the full one-click local AI runtime install, the mascot's selection copy, Page Down scrolling and screen capture in browsers and Office (including multiple monitors and display scaling), typing in the mascot's ask box, the tray icon on light and dark taskbars, the Glass appearance, Codex found through an npm install, and the learning folder on a real Windows profile.
- Automated release checks cover unit tests, native startup on both platforms, and Windows install/uninstall. They do not sign in to company services or test live AI providers; each provider needs its own connection test.
- Hyland knowledge lookup needs a local Codex executable with your own sign-in and the Atlassian connector. Nothing is sent to Teams or written to Jira/Confluence automatically.
