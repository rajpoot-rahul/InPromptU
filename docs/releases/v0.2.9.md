# Impromptu v0.2.9 — Mac and Windows

Mac Apple Silicon and Windows x64 installers built and tested from the same commit. This release makes OpenRouter the first step in the Prompt workspace, moves local AI into a quiet Phase 2 tab, and adds opt-in agent context from recent conversations.

## Downloads

- **[Mac installer (.pkg)](https://github.com/rajpoot-rahul/InPromptU/releases/latest/download/Impromptu-Mac-Apple-Silicon-Installer.pkg)** — Apple Silicon, macOS 13 or later.
- **[Windows installer (Setup.exe)](https://github.com/rajpoot-rahul/InPromptU/releases/latest/download/Impromptu-Windows-x64-Setup.exe)** — Windows x64.
- `release.json` and `SHA256SUMS.txt` record the version, commit and checksums of both installers.

Save drafts and quit the old app before upgrading. Settings and saved sessions are retained.

## What's new

- **OpenRouter-first setup in the Prompt workspace** ([#6](https://github.com/rajpoot-rahul/InPromptU/pull/6)). A fresh profile opens with a four-step **Start with OpenRouter** card: open the OpenRouter keys page, paste a key (kept in memory only, never written to disk), choose a model (defaults to `openrouter/free`), then **Test & use OpenRouter**. Nothing is saved if the test fails. **Other options** lead to Amazon Bedrock, Hugging Face or the Local AI tab. The card hides once a provider is configured or after **Not now**.
- **Phase 2 · Local AI tab** ([#6](https://github.com/rajpoot-rahul/InPromptU/pull/6)). Local model setup moves out of the Prompt workspace into a new sidebar view with three sub-tabs:
  - **Overview:** runtime status, active local model, local-only mode and shortcuts.
  - **Set up & models:** the guided one-click setup, installed models and **Download another model**.
  - **Settings:** local runtime address (localhost only), model detection, the model used by the Prompt workspace and local-only mode.

  A fresh profile no longer probes localhost until you open Phase 2.
- **Local AI kept quiet and product-neutral** ([#9](https://github.com/rajpoot-rahul/InPromptU/pull/9)). Because local AI is a Phase 2 preview, the app no longer shows the local runtime's brand name, port, terminal commands or "not responding" errors. When it isn't set up, the Overview shows **Runtime: Not set up** with a **Set up local AI** button, and nothing else draws attention to it: no top-bar health dot, no workspace attention card, no warning notices or unprompted toasts. The mascot always reads **Ready**, and its screen-reading actions are disabled until Phase 2. The provider is listed as **Local AI · Phase 2 preview**. Only the one-click install consent dialog names the third-party software, because consent requires it.
- **One provider order everywhere** ([#6](https://github.com/rajpoot-rahul/InPromptU/pull/6)). Settings, Context packs and Hyland latest learning list providers as OpenRouter, then Amazon Bedrock, then Hugging Face, then the local model (followed by Custom API and the offline template where applicable). Existing settings keep working unchanged.
- **Opt-in agent context** ([#7](https://github.com/rajpoot-rahul/InPromptU/pull/7)). When improving a draft, the Prompt workspace can include a selected conversation from recent local Codex history or from ChatGPT messages loaded in the browser.
  - A paired Chrome/Edge **ChatGPT browser extension** sends loaded messages to the app through an authenticated **context bridge** that listens only on this computer. It never reads hidden reasoning, unopened conversations or attachments. The extension is exported to a stable folder so Chrome or Edge can load it.
  - Collecting context and including it are separate opt-ins in **Settings**, with an excerpt preview and an explicit choice when a vague prompt matches more than one conversation. Collected context is kept in memory only and is cleared when you disconnect or quit. It is never added to the My progress prompt log.
  - Context packs are now hidden by default behind **Settings → Show Context packs**; saved packs are kept.
  - Layout: the top banner is gone, the sidebar scrolls, and native window controls are kept on Windows and macOS. Codex is also found in Mac app bundles and both Homebrew locations.
- **Cross-platform desktop CI** ([#7](https://github.com/rajpoot-rahul/InPromptU/pull/7)). Desktop checks now run on Windows, Apple Silicon macOS and Intel macOS, including native Mac packaging, resource checks and startup in all five themes. Brief Windows file locks during log saves are retried.

## Known limitations

- Builds and installers are unsigned, and the Mac build is not notarized. macOS Gatekeeper and Windows SmartScreen may warn before opening them; managed devices may need IT approval.
- The repository is private, so the download links above require signing in to GitHub with access to it.
- The release installers are for Apple Silicon Macs and Windows x64. Intel Macs are covered by CI only; there is no Intel Mac installer.
- Still to verify: the OpenRouter path end to end with a real key, and hands-on testing of this release on a real Windows PC. Automated checks cover unit tests, native startup on both platforms and Windows install/uninstall, but not live AI providers.
