Hyland-wide hackathon

Every team writes its own prompts.
Answers come back inconsistent, unchecked and expensive.

The Task Harness turns any AI task into a controlled pipeline: a fixed template defines the task, code checks every answer, and anything doubtful is retried or sent to a person, never silently passed on.

Try it →

😕 Inconsistent

The same request returns different formats: "null" in one answer, "0" in another, a minus sign somewhere else.

🙈 Unchecked

Nobody verifies that a date or total really came from the document. Wrong answers flow straight into business systems.

💸 Expensive

Teams reach for the biggest model to be safe, paying more and waiting longer for every document.

How the harness works

  1. Pick a taskVersioned template
  2. CleanNormal code tidies the document
  3. Build promptRules, fields, output format
  4. AI answersApproved model
  5. CheckFormat, source, logic, sums
  6. Retry or flagOne retry, then human review
  7. LogEvery step recorded

From one task to every Hyland team

    

      
📚 Template library
Ready-made, versioned templates: invoices, contracts, claims, test-log summaries, classification.

      
🧩 Teams add their own
A simple screen for teams to define fields, rules and checks without writing prompts.

      
🔒 Approved models only
Calls go through the company's approved models and accounts, with no personal keys.

      
🧾 Audit trail
Every prompt, answer, check and retry is logged against the template version that produced it.

      
💰 Right-size the model
Show when a cheaper, faster model plus checks is good enough, task by task.

      
⚡ HS1 as a fast check
Optionally use HS1 for quick yes/no judgments, such as "is this document an invoice?", before the pipeline runs.

    

    

      Honest limits today: 30 synthetic invoices, one task, and checks written for that task. Next step: test on real, approved documents from one product team.
